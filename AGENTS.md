# Project instructions

Before each set of project file edits, create a checkpoint with:

    python checkpoint.py "brief reason"

This records source and configuration files in a timestamped directory under
`checkpoints/`, with hashes and a reason. Keep checkpoints local. Exclude course
data, model weights, indexes, environments, and earlier checkpoints.
Create another checkpoint after completing a change, labelled `after ...`.
Report the checkpoint location when delivering changes.
